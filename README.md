# Sentiment Analysis using Random Forest (IMDB Reviews)

## Overview
This project performs binary sentiment classification (positive/negative) using:
- Text cleaning (HTML removal, stopwords)
- TF-IDF Vectorization
- Random Forest Classifier

## Dataset
IMDB Movie Review Dataset (10,000 rows used)

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python sentiment_analysis_rf.py`

## Accuracy
Achieved ~85% accuracy using Random Forest + TF-IDF.
